📐 Prompt 结构解析



      一个好的选题 Prompt 由以下五个模块组成，每个模块都有其作用：
    



── 研究情境 ──
研究领域 + 学段 + 关注方向

── 策略要求 ──
根据所选策略注入必要的技术、问题、政策、理论、群体、比较对象或教学策略

── 真实案例 ──
参考真实立项课题的问题结构与命名方式

── 输出任务 ──
生成候选题目 → 筛选 → 说明研究问题、创新点、对象和方法
