需要测量的构念

构念就是问卷要测的东西，一般就是你研究里的变量。默认有一个自变量和一个因变量，不够就增加。每行填名称、选变量类型；维度可选，不填就按第三步选定量表的维度。从研究逻辑工具导入的会自动填好。干预变量不测量，默认不纳入问卷；用观察、测验等其他工具测量的，取消“纳入问卷”。

第四步：编制题项

每个构念单独走一遍：在上方选中构念，按编号依次完成，再切到下一个。改编成熟量表要先粘贴原题，AI 只改编你给的题目；每个维度一般保留 3—5 题。
